# Metrics API Gateway

**Дисциплина:** «API интерфейсы информационных систем»
**Тема:** Разработка API-шлюза для системы мониторинга серверных метрик с использованием Docker и Ansible.

## О проекте
Проект представляет собой REST API на FastAPI, который выступает в роли шлюза между пользователем и системой мониторинга Prometheus. Пользователю не нужно знать язык запросов PromQL — достаточно отправить простой JSON-запрос.

API поддерживает два эндпоинта:
- `GET /health` — проверка работоспособности сервиса.
- `POST /api/v1/metrics` — получение метрики (cpu или memory).

## Стек технологий
- **Python 3.11 + FastAPI** — бэкенд API-шлюза.
- **Prometheus + Node Exporter** — сбор и хранение метрик.
- **Docker + Docker Compose** — контейнеризация всех компонентов.
- **Ansible** — автоматизация развертывания.
- **Bash** — имитация CI/CD пайплайна.
- **Git** — контроль версий.
- **YAML** — конфигурационные файлы.

## Архитектура
Проект состоит из трех Docker-контейнеров, объединенных в общую сеть:
1. **node-exporter** (порт 9100) — собирает системные метрики с хоста.
2. **prometheus** (порт 9090) — хранит метрики и предоставляет внутренний API.
3. **my-api** (порт 8000) — API-шлюз, который ходит в Prometheus и возвращает данные пользователю.
